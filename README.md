# Pepix

Las películas de Gero y Ro: lo que cada uno le recomienda al otro y lo que quieren ver juntos.
Marcado de vistas, estrellas, formato, reseñas, plataformas y código compartido para sincronizar.

App: https://gero77.github.io/pepix/

Pósters, datos y plataformas: TMDB y JustWatch. Esta app usa la API de TMDB pero no está avalada ni certificada por TMDB.

Al publicar cambios, subir `VERSION` en `sw.js`.
